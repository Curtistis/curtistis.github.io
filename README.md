# 作品集

用 GitHub Pages 托管的纯前端项目合集，每个子文件夹是一个可以直接在浏览器打开的页面。

## 目录约定

```
portfolio/
├── index.html          首页:按类别列出所有项目的链接
├── 3d/                 3D 交互类
│   └── hexapod/        六轴外固定架演示 → /3d/hexapod/
├── csv-insight/        CSV 数据洞察看板 → /csv-insight/
└── (新类别)/(新项目)/index.html
```

- 每个项目一个文件夹，入口文件必须叫 `index.html`，访问地址就是 `https://<用户名>.github.io/<文件夹路径>/`。
- 项目里的 JS、CSS、图片放在同一个文件夹，用相对路径引用(如 `./app.js`)。
- 加新项目后，在根目录 `index.html` 对应类别里复制一张卡片，改链接和文字。

## 项目

| 项目 | 类别 | 说明 |
|---|---|---|
| [六轴外固定架演示](3d/hexapod/) | 3D 交互 | 畸形参数 → 逆运动学 → 每日杆长处方 + 3D 复位动画 |
| [CSV 数据洞察看板](csv-insight/) | 数据可视化 | 字段画像、筛选、六类图表、分组聚合、导出 |
